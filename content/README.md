# content/ — authored source content

Pre-compilation source content: map heightmaps and feature layers, and balance spreadsheets that are
exported into `packages/com.brinehold.content/Data/`.

Compiled outputs are produced by `src/Brinehold.Tools.MapCompiler` and validated by
`src/Brinehold.Tools.ContentCheck`.

**Originality rule:** no asset, name, map or text may be copied from any existing game. See
`GAME_DESIGN.md` §0.

*Status: scaffold only (M0).*
